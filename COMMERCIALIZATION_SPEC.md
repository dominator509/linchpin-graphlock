# Commercialization / Licensing Specification

## Purpose
Turn a protected invention workspace into a disclosure-safe, evidence-backed licensing/sale/investor package without implying a guaranteed valuation, buyer, investment outcome, or transfer validity.

## Asset readiness
Build a chain-of-title timeline from inventor/owner records, assignments, public Assignment Search evidence, liens/security-interest warnings when available, filing/grant/legal-status events, maintenance/deadline state, remaining-life assumptions, related families/continuations, know-how dependencies and unresolved ownership/inventorship questions. USPTO recordation is represented as recordation evidence, not legal validation.

## Buyer / licensee intelligence
Rank targets by product/technology adjacency, cited/citing patents, assignee portfolio overlap, public R&D/product strategy, regulatory/standards position, geographic reach, financial capacity and strategic gap. Every target reason cites source evidence and date. User-supplied CRM/contact data stays separately permissioned.

## Valuation workbench
Support cost, market-comparable and income/DCF approaches plus real-options and Monte Carlo scenario analysis. All values are ranges tied to explicit assumptions: remaining economic life, development cost/time, probability/risk inputs, addressable use cases, adoption, margin/royalty assumptions, exclusivity, territory, field-of-use, enforcement burden, substitutes/design-arounds, complementary know-how and buyer-specific synergies. Sensitivity tables show which assumptions dominate. The UI labels these as planning scenarios, not certified appraisals.

## Deal architect
Model assignment, exclusive/non-exclusive license, field-of-use, territory, milestone, minimum royalty, running royalty, upfront, sublicense, grant-back, prosecution-control and enforcement-cost scenarios as negotiation variables. Contract language is generated only as draft issue-spotting material for professional review.

## Disclosure-safe go-to-market
Generate a non-confidential teaser, technical one-pager, claim-to-benefit map, buyer-specific pitch, diligence index and gated data-room package. The Disclosure Firewall blocks unpublished enabling detail unless policy finds a qualifying filing event or an explicit human override is logged.

## Transaction handoff
For ownership transfers, generate a checklist/package and guided human handoff to the current USPTO Assignment Center; never claim unattended recordation or that USPTO recordation proves transaction validity. Store receipt/document hashes and independently read back public record state when available.
