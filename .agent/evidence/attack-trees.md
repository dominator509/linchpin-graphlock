- Method: goal-first attack trees in the Schneier sense: a root adversarial goal decomposed into AND/OR refinements, with each leaf either mitigated by a named control (bound to a symbol that must exist) or left OPEN/PARTIAL with the decision that keeps it that way

## AT-1 — exfiltrate the invention content from the device

Threat: **T-04**

The highest-value goal for this product: the disclosure is the asset. Three independent routes are considered, and the tree is an OR because any one of them suffices for the attacker.

| Node | Kind | Description | Status | Evidence |
| --- | --- | --- | --- | --- |
| `AT-1.1` | OR | route the content off-device through the provider boundary | — | see children |
| `AT-1.1.1` | leaf | point the product at a remote inference endpoint and let it send prompts there | MITIGATED | the endpoint is validated before any I/O and a non-loopback host is refused with POLICY, with no attempt made; the refusal is asserted at both the transport and the product-command layer, and the same negative runs against the packaged executable |
| `AT-1.1.2` | leaf | exploit a credentialed remote lane once one is wired | OPEN | no credentialed provider lane exists in this architecture, so neither the egress nor the credential-failure behaviour of one has been executed |
| `AT-1.2` | OR | capture the content in something the product writes down | — | see children |
| `AT-1.2.1` | leaf | have a credential or invention fragment land in telemetry, diagnostics or an incident capsule | MITIGATED | redaction runs on the diagnostics path before storage, an induced failure is asserted to carry its correlation id with a planted credential absent from every recorded detail, and the capsule export guard refuses a surviving registered secret |
| `AT-1.2.2` | leaf | export a filing package or evidence bundle that carries restricted content | MITIGATED | the export gateway refuses restricted content, the support matrix refuses a package whose limitations are unanchored, and a package never claims a document format the product cannot produce |
| `AT-1.2.3` | leaf | leave unlabelled secret material in free text that the redactor cannot attribute to a key or token shape | PARTIAL | the redactor removes values it can attribute to a key name or a known token shape, and a property-style test covers punctuation-wrapped and quoted forms |
| `AT-1.3` | OR | read the vault from the filesystem | — | see children |
| `AT-1.3.1` | leaf | read the vault file directly as the logged-in user or as malware running with the user's rights | PARTIAL | the vault is a device-local SQLite database with content-addressed blobs; workspace scoping and the audit chain are asserted, but the file is readable by anything running as the user |
| `AT-1.3.2` | leaf | reach the vault through a path or archive traversal from a crafted import | MITIGATED | path and archive-entry hardening rejects absolute paths and traversal, verified by a property test over a generated corpus and by a mutation proof that removes the guard |

Unmitigated or partial leaves and why they stay that way:

- `AT-1.1.2` (OPEN): DOD-014 is PARTIAL for exactly this reason: the pack's governance (terms review) precedes any provider integration, and wiring a lane is an owner decision under change control
- `AT-1.2.3` (PARTIAL): a secret pasted with no key name and no recognisable shape is not detectable by either layer; stated as a residual in the threat model rather than claimed closed
- `AT-1.3.1` (PARTIAL): no OS-encrypted container exists and the only KeyringStore is an in-process map -- the product's own scope map (UO-01) states this limitation, and the threat model records it as accepted risk R-2

## AT-2 — destroy or forge the conception record

Threat: **T-02**

For a patent workflow the record of who conceived what is the product's output; destroying it is a denial of the user's rights, and forging it is worse.

| Node | Kind | Description | Status | Evidence |
| --- | --- | --- | --- | --- |
| `AT-2.1` | OR | destroy the durable state | — | see children |
| `AT-2.1.1` | leaf | corrupt or delete the vault and its WAL siblings | MITIGATED | the recovery drill injects total loss and in-place corruption repeatedly, recovers through the production command, and reconciles the recovered state by content digest through an independent connection with measured RPO/RTO against an enforced threshold |
| `AT-2.1.2` | leaf | make a restore silently replace live state with an empty database | MITIGATED | a mistyped backup path is refused instead of created, the destination is recreated and quarantined when missing, and every recovery is reconciled by digest |
| `AT-2.2` | OR | forge or rewrite the record without detection | — | see children |
| `AT-2.2.1` | leaf | edit the audit chain after the fact | MITIGATED | the audit chain is hash-chained and a test tampers with a stored entry and asserts detection |
| `AT-2.2.2` | leaf | present AI-generated content as human conception | MITIGATED | conception events carry an origin label that cannot be conflated, and the ledger read separates the two origins at the product boundary |

## AT-3 — get a tampered or unauthorised build installed and run

Threat: **T-08**

The distribution path carries no signature, so the tree concentrates on what IS checked.

| Node | Kind | Description | Status | Evidence |
| --- | --- | --- | --- | --- |
| `AT-3.1` | OR | substitute the artefact in transit or at rest | — | see children |
| `AT-3.1.1` | leaf | swap the executable for one that opens a debug port and leaks through it | MITIGATED | the production artifact is asserted to open no debug port, with the probe baseline-checked, pid-attributed and liveness-checked so a dead process cannot pass vacuously |
| `AT-3.1.2` | leaf | ship a package whose payload is not the built binary | MITIGATED | the installed executable is bound to the digest of the payload the MSI itself carries (extracted with msiexec /a), which is what exposed the bundler relinking the binary during packaging |
| `AT-3.2.1` | leaf | distribute through a compromised channel | OPEN | digests are published and verified out of band, and the build is reproducible, but nothing binds authorship |

Unmitigated or partial leaves and why they stay that way:

- `AT-3.2.1` (OPEN): the release is UNSIGNED (ADR-003): a digest proves integrity against an out-of-band value, not authorship; accepted risk R-1
