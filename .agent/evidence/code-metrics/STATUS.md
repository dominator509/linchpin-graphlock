## Limits, stated rather than implied

complexity is decision-token counting, not a dataflow analysis: it ranks functions for review and enforces a ceiling, and it is blind to nesting depth, state space and architecture. Panicking-call counts include arguments and do not distinguish an infallible unwrap from a load-bearing one.

function with 20 `if` conditions, an `unsafe` block and a `todo!`, and asserts each is
measured. A metrics gate that has never seen a defect cannot be trusted.
