feat(DOD-037): operator diagnostics dashboard

The last named signal of DOD-037 was a dashboard: every signal existed over IPC
and was rendered nowhere, which is why the clause sat at PARTIAL. Settings now
carries an Operator diagnostics panel rendering readiness with its measured
detail, command counts with failure rate and p50/p95 durations, derived alerts, a
table of recent outcomes (command, outcome, error class, duration, correlation id)
and the correlation-tagged traces -- read from get_diagnostics, not recomputed.

Proven at three layers, each with an assertion that discriminates a real
dashboard from a constant:
- browser lane: heading and control exist, and clicking with no IPC reports the
  missing backend instead of showing a healthy panel;
- exact-artifact lane: the button is CLICKED and the RENDERED panel is read back,
  and it must contain the correlation id of the record_conception call made
  earlier in the same run plus its trace (measured: "Commands recorded: 1 (1 ok,
  0 failed, failure rate 0); p50 11ms, p95 11ms", "Traces: 1 correlation-tagged
  span(s) -- latest <correlation>:record_conception");
- rust boundary test: an induced failure must yield DEGRADED, a storage alert, a
  FAILED entry with POLICY class, duration, timestamp, correlation id, a naming
  alert and a matching trace, while a planted credential stays absent.
