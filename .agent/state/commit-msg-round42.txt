feat(DOD-038): execute and label an abbreviated endurance trial

DOD-038's own OR ELSE says an abbreviated trial "is labeled separately" and is
"never PASS for the full requirement", so this round EXECUTED the trial and
strengthened the evidence rather than the label: the status stays PARTIAL.

apps/desktop/src-tauri/tests/soak_abbreviated.rs runs a bounded trial against the
real paths -- every cycle writes through record_conception_keyed under one client
key so a duplicate is caught rather than accumulated, every 20th cycle reads the
whole ledger back through the product's own read path and checks the count, and
every 50th cycle takes a backup, DESTROYS the vault file and restores it,
asserting reconciliation, so recovery runs under load rather than only in a quiet
drill. Working set is sampled by an EXTERNAL observer (PowerShell), not
self-reported. Measured, 600s:

  17 050 cycles, 0 errors, 17 050 events, 341 recoveries under load,
  564 bytes/event, working-set growth 2.4 MB over the run (no monotonic leak).

The run LABELS ITSELF: below 300s it reports SMOKE_SUBSET and does NOT write
evidence, so the ordinary unit lane (30s default) can never overwrite an
abbreviated trial's report; at or above the floor it writes heartbeats, growth and
the epoch it ran against. The specification gap is recorded beside the evidence:
no soak/fuzz/stress duration or workload is specified anywhere in the repository,
so "their specified scale" has no value to complete. Fuzzing remains absent
(GEN-027 records no mutation-based fuzzing engine).
