# Observability
Structured traces/logs/metrics use correlation IDs and remain local by default. Never log raw credentials, source-document bodies, claim/spec text, invention names, or provider auth tokens. Provider spans contain adapter/version, purpose, egress class, timing, result class and artifact/evidence IDs. Research spans contain query ID, source adapter, cache path, result count and hash IDs. Crash capture creates an Incident first; export creates a separately redacted Repair Capsule. Opt-in remote telemetry, if later added, is an explicit feature with its own threat model and privacy proof.
